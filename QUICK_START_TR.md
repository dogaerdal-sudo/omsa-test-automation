# Hızlı Başlangıç

1. ZIP'i tamamen çıkart.
2. Bilgisayarda Microsoft Excel Desktop kurulu olsun.
3. İlk sefer `SETUP_AND_RUN.bat` dosyasına çift tıkla.
4. Kurulum bitince `http://localhost:8501` açılır.
5. Üst menüden `Loaders`, `Views` veya `Controls` seç.
6. Önce full liste gelir. İstediğin satırdaki `Launch` butonuna bas.
7. Açılan detay ekranında fixed master template görünür.
8. Altında o template'i populate etmek için gerekli dosyalar isim isim ayrı upload alanları olarak görünür.
9. Tüm required dosyaları yükle ve `Generate Excel` bas.
10. Excel Desktop arka planda açılır, template doldurulur, formüller recalculate edilir ve tamamlanmış dosya indirilebilir.

Sonraki açılışlarda `RUN.bat` yeterlidir.

GitHub'a kodu koymak için `INIT_GIT.bat` kullanılabilir. `templates_local/` GitHub'a gönderilmez; local kalır.
